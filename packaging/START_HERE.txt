A / B MODEL
-----------
A is always the currently selected EtherVersions node shown in NOW PLAYING.
Auditioning B does not change A, does not move HEAD, and does not rewrite lineage.

B is selected deterministically from the most relevant alternate version:
1. promoted HEAD when A is not HEAD
2. next sibling when A already is HEAD and siblings exist
3. direct child when A is a root with children
4. parent as a fallback

This keeps comparison immediate without requiring a second file picker.

SYNCHRONIZED AUDITION
---------------------
EtherBeat queries the current MCI playback position in milliseconds before switching A/B.
The alternate audio is opened and seeks to the same timeline position before playback resumes.

Typical flow:

  A playing at 00:42.350
      -> A/B SYNCHRONIZED
  B opens
      -> seek 00:42.350
      -> play

Switching back repeats the same process in the opposite direction.

The selected EtherVersions node remains A while B is being auditioned.

ETHERDNA DIFFERENCE VIEW
------------------------
EtherCompare V0.1 is a portable core module. It compares two persisted EtherDNA objects and reports measurable deltas.

Current display includes:
- DNA preservation similarity percentage
- delta low-end weight
- delta brightness
- delta rhythmic activity
- delta energy

The core also computes:
- bass delta
- mid delta
- treble delta
- beat-peak delta
- darkness delta
- spectral-center delta
- 32-band spectrum RMSE

IMPORTANT: EtherCompare similarity means measured audio-identity preservation. It is NOT a subjective "better song" score. EtherCritic and future taste/semantic heads remain separate responsibilities.

VERSION + COMPARE FLOW
----------------------
  ORIGINAL
     -> VARIATION A
     -> VARIATION B [HEAD]

While A is selected:
  A = VARIATION A
  B = HEAD / VARIATION B

  A/B SYNCHRONIZED
      -> audition B at the same playback position
      -> audition A at the same playback position
      -> inspect EtherDNA deltas
      -> PROMOTE only if the user chooses

No compare action deletes branches or moves HEAD.

CURRENT LIMITS
--------------
- Synchronized A/B is based on MCI millisecond seek; sample-accurate phase-locked dual-engine switching comes later with a dedicated playback engine.
- The comparison panel shows a compact subset of EtherCompare metrics; full spectra/overlay visualization can be added later.
- Extend remains intentionally blocked until continuation behavior is separately validated.
- ACE does not claim true component locks or isolated drum/melody/chord conditioning through this adapter.
- SEARCH x4 is sequential until provider-native batching or a dedicated fast Draft engine is wired.
- EtherCritic remains DSP-derived; learned semantic/taste heads come later.
- Pleiadian taste adaptation is not trained yet.
- Dedicated Vocal provider is not wired yet.
- No private corpus, vocals, LoRAs, checkpoints or training data ship in this public package.
