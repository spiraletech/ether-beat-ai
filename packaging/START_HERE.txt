NEW IN V0.2C // ETHERDNA V0.1
----------------------------
EtherBeat now persists measurable audio identity after native analysis.

Whenever a WAV/MP3/FLAC is successfully analyzed by EtherBeat, the analyzer builds an EtherDNA object and writes a sidecar beside the audio:

  song.wav
  song.wav.etherdna.json

EtherDNA V0.1 stores:
- schema/version
- source audio lineage
- sample rate / channels / analyzed duration
- energy
- bass / mid / treble
- beat peak
- 32-band normalized spectrum
- derived low-end weight
- brightness
- darkness
- rhythmic activity
- normalized spectral center

These derived values are measurable summaries, not guessed genres.

COMPOSER BRIDGE
---------------
EtherComposer can now load the .etherdna.json sidecar associated with a reference_audio request.
When DNA exists, Composer injects the measured reference identity into the renderer blueprint before model invocation.

This establishes the engine path:

  AUDIO
    -> EtherPlay-derived native FFT
    -> EtherDNA
    -> persistent sidecar
    -> EtherComposer
    -> model router / future control engines

Existing CREATE behavior still works without a reference.
Reference-conditioned generation modes are still being built, but the persistent data contract they will consume now exists and is tested.

SONG LAB
--------
Selecting reference audio continues to run Windows Media Foundation decoding + the native 1024-point Hann FFT.
Successful analysis now also emits EtherDNA automatically.

NOW PLAYING
-----------
Generated tracks analyzed by Now Playing also receive EtherDNA sidecars automatically, so EtherBeat can later compare generations, rank candidates and learn taste from measurable output traits.

CURRENT LIMITS
--------------
- EtherDNA V0.1 is DSP-derived; learned CLAP/MERT-style embeddings are a later layer.
- Reference audio is measurable and persistent, but dedicated reference/extend/repaint renderer mappings are still future steps.
- EtherComposer V0.1 remains deterministic and inspectable.
- No private corpus, vocals, LoRAs, checkpoints or training data ship in this public test package.
