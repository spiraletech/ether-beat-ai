UI ANCHOR
---------
EtherBeat keeps the EtherPlay-derived navigation spine intact:

  home | create | library | now playing | song lab | engine

V0.2O evolves the V0.2N NOW PLAYING workspace instead of redesigning the shell. Search, EtherControl, EtherVersions and EtherCompare stay intact; EtherTimeline adds visual region selection for source-audio repaint.

NEW IN V0.2O // ETHERTIMELINE V0.1
----------------------------------
NOW PLAYING adds a real audio-derived timeline strip inside the analyzer workspace.

The timeline displays:
- a normalized 128-bin time-energy envelope
- the current repaint selection
- start/end time labels
- the current playback position
- explicit A-source status while EtherCompare B is being auditioned

The envelope is not decorative. Media Foundation collects per-window RMS energy during the existing 1024-sample FFT/decode pass, then compresses those measurements into 128 left-to-right bins. No second audio decode is required.

DRAG TO SELECT
--------------
Drag directly across the EtherTimeline waveform to select the source region that Replace Section should repaint.

Example:

  [---- waveform ----[ SELECTED ]---- waveform ----]
                       0:08.20 -> 0:16.75

The selection immediately updates the existing START and END precision fields in EtherControl.
Pressing REPLACE SECTION therefore uses the same typed GenerationRequest / ACE repaint path that V0.2K+ already validated.

The numeric START / END boxes remain available for exact manual adjustment.

SELECTION SEMANTICS
-------------------
EtherTimeline V0.1 owns selection math outside Win32.

It provides:
- normalized drag -> seconds conversion
- reversed-drag handling
- duration clamping
- out-of-range clamping
- minimum 0.25-second edit region
- normalized playhead conversion

This keeps timeline semantics reusable when EtherBeat eventually replaces MCI/Win32 playback.

COMPARE SAFETY
--------------
EtherCompare keeps A as the selected EtherVersions node and B as the audition-only alternate.

The timeline always edits A.
If B is currently being auditioned, the timeline explicitly reports:

  B AUDITIONING, EDIT SOURCE REMAINS A

Dragging the timeline while listening to B never silently changes the repaint source to B.

REAL PLAYHEAD
-------------
The timeline polls the existing MCI playback position and draws a live playhead across the selected A-source timeline.
A lightweight UI timer invalidates only the timeline region while NOW PLAYING is active.

ANALYSIS ENVELOPE
-----------------
AudioAnalysis now includes:

  timeline_envelope[128]

The Windows Media Foundation analyzer records each FFT window's RMS energy and builds a normalized envelope from average + local peak energy. Existing EtherDNA spectrum and critic measurements remain unchanged.

CURRENT LIMITS
--------------
- EtherTimeline V0.1 visualizes a real time-energy envelope, not full sample-resolution waveform peaks yet.
- Timeline playback/seek still uses MCI millisecond positioning; sample-accurate playback comes later with the EtherPlay playback engine.
- Region selection currently drives Replace Section; Extend remains intentionally blocked until continuation behavior is separately validated.
- ACE does not claim true component locks or isolated drum/melody/chord conditioning through this adapter.
- SEARCH x4 is sequential until provider-native batching or a dedicated fast Draft engine is wired.
- EtherCritic remains DSP-derived; learned semantic/taste heads come later.
- Pleiadian taste adaptation is not trained yet.
- Dedicated Vocal provider is not wired yet.
- No private corpus, vocals, LoRAs, checkpoints or training data ship in this public package.
