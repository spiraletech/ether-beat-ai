ETHERBEAT // ALIEN WORKSHOP V0.2A

STUDIED FROM ETHERPLAY V0.38
----------------------------
EtherBeat now uses an EtherPlay-style navigation spine instead of one giant generator dashboard:

  home | create | library | now playing | song lab | engine

HOME
- Shows foundation-model and engine state.
- ACE-Step 1.5 is PRETRAINED. Custom Pleiadian training is NOT required for basic generation.

CREATE
- Real text-to-instrumental path through the managed local ACE-Step backend.
- Prompt, BPM, key, duration and seed controls.
- First Generate automatically provisions/wakes the local model runtime. No BAT or terminal is required.

LIBRARY
- Scans EtherBeat's private local generated-audio library.
- Click a generated track to send it to NOW PLAYING.

NOW PLAYING
- Plays the generated audio inside EtherBeat.
- Displays the native EtherPlay-derived 32-band frequency analysis for the generated result.

SONG LAB
- Choose WAV/MP3/FLAC reference audio.
- Windows Media Foundation decodes the file and the native 1024-point Hann FFT analyzes its musical frequency DNA.

ENGINE
- Shows whether the runtime is installed and whether the local API is online.
- START / CHECK explicitly validates/wakes the private model engine.
- If generation fails, EtherBeat moves you here and surfaces the actual engine error instead of silently doing nothing.
- Foundation model: ACE-Step 1.5 PRETRAINED.
- Pleiadian adapter: NOT TRAINED YET. That affects private style/taste, not whether base generation functions.

LOCAL DATA
----------
Runtime:
  %LOCALAPPDATA%\EtherTech\EtherBeat\runtime

Generated library:
  %LOCALAPPDATA%\EtherTech\EtherBeat\library

FIRST GENERATION NOTE
---------------------
A local Udio-class workflow needs large model files. The first generation can require a substantial one-time download/model initialization. Later launches reuse the local runtime. EtherBeat owns this machinery and no visible server window is required.

CURRENT LIMITS
--------------
- Text-to-instrumental is the real generation path.
- Reference analysis is real.
- Reference-conditioned generation / Extend / Variation still need dedicated ACE-Step repaint/cover mappings.
- Detailed byte-level model-download progress is not yet exposed in the UI.
- No private corpus, vocals, LoRAs, checkpoints or training data ship in this public test package.
