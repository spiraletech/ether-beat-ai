NEW IN V0.2F // ETHERCRITIC V0.1
-------------------------------
EtherBeat now has an explainable candidate-ranking layer above EtherDraft.

EtherCritic does not guess which draft is "best" from filenames, seeds or provider order.
It consumes persistent EtherDNA measurements and compares each candidate against the numeric intent produced by EtherComposer.

SCORING HEADS
-------------
V0.1 scores five measurable dimensions:
- energy match
- low-end / bass-weight match
- rhythmic-activity match
- spectral-character / brightness match
- texture proxy match

Default normalized weighting emphasizes bass and rhythmic fit while preserving energy, spectral character and texture.
Every component score and the final weighted score are written to the critic manifest.

NO DNA = NO FAKE SCORE
----------------------
A successful audio artifact without a .etherdna.json sidecar is not assigned invented confidence.
It remains visible in the report but is marked unscored and falls behind candidates with real measurements.

That makes the intended pipeline explicit:

  draft candidate
      -> native EtherPlay-derived analysis
      -> EtherDNA
      -> EtherCritic
      -> ranked candidate

CRITIC MANIFEST
---------------
EtherCritic writes:

  <draft-batch-id>.ethercritic.json

The manifest records:
- schema etherbeat.critic.v1
- source draft batch ID
- Composer target values
- normalized critic weights
- winner candidate index
- winner audio path / seed
- full ranking
- per-candidate component scores
- provider lineage
- DNA availability
- explainable notes/errors

TESTED ETHERCRITIC CONTRACT
---------------------------
Automated tests stage four draft candidates with deliberately different audio identities.
Candidate 2 is constructed to match the Composer target and must win the ranking.
Candidate 3 deliberately has no EtherDNA sidecar and must remain unscored rather than receiving fabricated confidence.

The tests verify:
- deterministic winner selection
- component-weighted score near 1.0 for the intended match
- missing-DNA candidate falls behind measured candidates
- winner candidate index / seed / path persist
- etherbeat.critic.v1 manifest is created
- explainable missing-DNA note persists
- Windows/MSVC and Ubuntu/GCC execute the same critic assertions

CURRENT LIMITS
--------------
- EtherCritic V0.1 uses deterministic DSP-derived EtherDNA only.
- Texture scoring is an explicit spectral proxy until richer flatness/learned texture features arrive.
- Learned CLAP/MERT-style semantic scoring is a later critic head.
- User taste / Pleiadian preference weighting is not trained yet.
- Dedicated Control and Vocal providers are not wired yet.
- No private corpus, vocals, LoRAs, checkpoints or training data ship in this public test package.
