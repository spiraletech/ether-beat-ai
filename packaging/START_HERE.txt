ETHERBEAT // ALIEN WORKSHOP V0.2K

UI ANCHOR
---------
EtherBeat keeps the EtherPlay-derived navigation spine intact:

  home | create | library | now playing | song lab | engine

V0.2K does not redesign the shell. It turns NOW PLAYING into a producer workspace by exposing the live source-audio control capabilities added in V0.2J.

NEW IN V0.2K // ETHERCONTROL UI V0.1
------------------------------------
NOW PLAYING now uses a split workspace:

  left  = EtherPlay-derived frequency analyzer
  right = ETHERCONTROL // LIVE

The Control card exposes:
- producer instruction
- reference strength (0..1)
- repaint start time
- repaint end time
- VARIATION
- REPLACE SECTION

The currently loaded Now Playing track is automatically used as the source audio.

LIVE USER FLOW
--------------
VARIATION:
  current track
      -> producer instruction
      -> reference strength
      -> EtherControl typed request
      -> ModelRouter Control role
      -> managed ACE-Step cover task
      -> new WAV version
      -> native audio analysis
      -> NOW PLAYING

REPLACE SECTION:
  current track
      -> producer instruction
      -> validated start/end window
      -> reference strength
      -> EtherControl typed request
      -> ModelRouter Temporal Control
      -> managed ACE-Step repaint task
      -> new WAV version
      -> native audio analysis
      -> NOW PLAYING

ORIGINAL PRESERVATION
---------------------
Control operations never overwrite the loaded source file.
New control renders are written under:

  %LOCALAPPDATA%\EtherTech\EtherBeat\library\control\<source-stem>\

The Library scan is recursive in V0.2K, so generated control versions remain loadable from the existing Library screen.

TYPED UI BOUNDARY
-----------------
A portable ControlUiRequestFactory now converts GUI state into GenerationRequest objects.
The Win32 shell does not hand-build ACE JSON.

The factory validates:
- source track exists logically
- producer instruction is present
- reference strength is 0..1
- Replace Section end is later than start
- repaint window stays inside the measured source duration

Reference strength also derives a conservative mutation amount for the provider-neutral request.

STATE CLEANUP
-------------
NOW PLAYING analysis and SONG LAB reference analysis are now separate state objects.
Analyzing a Song Lab reference no longer overwrites the spectrum/duration state used by Now Playing controls.

STRICT CAPABILITY TRUTH
-----------------------
ACE currently supports through EtherBeat:
- TextToInstrumental
- Variation
- AudioToAudio
- ReferenceAudio
- ReplaceSection
- DraftRole
- QualityRole
- ControlRole
- LocalRuntime
- TemporalControl

ACE still does NOT claim:
- Extend
- ComponentLocks
- isolated DrumConditioning
- isolated MelodyConditioning
- symbolic HarmonyConditioning

Unsupported controls remain blocked instead of silently discarded.

CURRENT CREATE PIPELINE
-----------------------

      -> NOW PLAYING

CURRENT LIMITS
--------------
- Extend remains intentionally blocked until continuation behavior is separately validated.
- ACE does not claim true component locks or isolated drum/melody/chord conditioning through this adapter.
- SEARCH x4 is sequential until provider-native batching or a dedicated fast Draft engine is wired.
- EtherCritic is still DSP-derived; learned semantic/taste heads come later.
- Pleiadian taste adaptation is not trained yet.
- Dedicated Vocal provider is not wired yet.
- No private corpus, vocals, LoRAs, checkpoints or training data ship in this public package.
