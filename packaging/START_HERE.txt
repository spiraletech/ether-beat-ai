---------
EtherBeat keeps the EtherPlay-derived navigation spine intact:

  home | create | library | now playing | song lab | engine

NEW IN V0.2I // ETHERCONTROL V0.1
--------------------------------
EtherBeat now has a provider-agnostic precision editing contract for producer-style generation jobs.

Supported control modes in the core contract:
- Variation
- Extend
- Audio-to-Audio
- Replace Section

CONTROL DATA
------------
GenerationRequest can now carry explicit control semantics instead of hiding producer intent inside prompt prose:

- reference audio
- mutation amount
- reference strength
- temporal edit start/end window
- component lock mask
- optional drum conditioning reference
- optional melody conditioning reference
- optional chord progression

Lockable musical components:
- drums
- bass
- melody
- harmony
- texture
- arrangement

ETHERCONTROL COMPILER
---------------------
EtherControl validates and normalizes control jobs before a renderer sees them.

Rules include:
- control jobs require reference audio
- mutation amount must be 0..1
- reference strength must be 0..1
- temporal windows require both start and end
- end must be later than start
- Replace Section always requires an explicit temporal window
- render intent is normalized to Control

The compiler emits an idempotent control blueprint containing mode, reference strength, mutation amount, locked components, temporal boundaries and optional drum/melody/harmony conditioning.

Locked components are compiled as preservation constraints, not casual style suggestions.

CAPABILITY-GATED ROUTING
------------------------
Provider Router now understands additional precision capabilities:

- ReplaceSection
- DrumConditioning
- MelodyConditioning
- HarmonyConditioning
- ComponentLocks
- TemporalControl

A provider must advertise every capability required by the job.
EtherBeat will not silently discard locks, edit windows, chord conditioning or reference controls just to make a request run.

Example:

  basic variation
      -> basic Control provider can qualify

  replace 8-16 seconds
  + lock drums/bass/melody/harmony/arrangement
  + drum reference
  + melody reference
  + chord progression
      -> only a precision Control provider advertising ALL requested features qualifies

If no provider qualifies, routing fails explicitly with a human-readable capability error.

CURRENT LIVE PROVIDER BOUNDARY
------------------------------
The current managed ACE-Step provider still advertises:

  TextToInstrumental + Draft + Quality

It does NOT currently advertise EtherBeat Control + ReferenceAudio precision capabilities.

Therefore V0.2I deliberately does not expose a fake Replace Section / lock-components UI button yet.
The Control engine contract is ready for a JASCO-style provider, another capable open model, or a future native Ether renderer without changing the existing EtherBeat UI architecture.

TESTED ETHERCONTROL CONTRACT
----------------------------
The dedicated precision-control smoke test verifies:

- Replace Section compiles a structured Control request
- five simultaneous component locks survive compilation
- temporal window survives compilation
- reference/mutation strengths survive compilation
- chord progression survives compilation
- control blueprint is idempotent and is not duplicated
- precision request routes only to a fully capable provider
- basic variation can still use a simpler Control provider
- a weak provider cannot silently strip requested locks
- invalid edit windows are rejected
- existing Core/Search/AutoPromote suites continue to pass
- Windows/MSVC and Ubuntu/GCC pass the same contract

CURRENT LIMITS
--------------
- No live precision Control provider is registered yet.
- ACE-Step remains the current Draft + Quality renderer.
- SEARCH x4 is sequential until provider-native batching or a dedicated fast Draft engine is wired.
- EtherCritic remains DSP-derived; learned semantic/taste heads are later.
- Pleiadian/user taste weighting is not trained yet.
- Dedicated Vocal provider is not wired yet.
- No private corpus, vocals, LoRAs, checkpoints or training data ship in this public test package.
